# Node.js + React Full Stack Evaluation

## Mandatory Skills
- Node.js
- React.js
- TypeScript
- PostgreSQL
- Kafka or Redis

## Strong Indicators
- Built scalable APIs
- Worked on microservices
- Experience with cloud deployment
- Good understanding of backend architecture
- Hands-on database optimization

## Interview Questions
1. Explain event loop in Node.js
2. Difference between SQL and NoSQL
3. What problem does Kafka solve?
4. Explain React component lifecycle
5. Why use TypeScript?

## Red Flags
- Only CRUD project experience
- Cannot explain architecture decisions
- No ownership in projects
- Weak debugging knowledge
- Resume keyword stuffing

## Good Candidate Signals
- Can explain tradeoffs clearly
- Worked across frontend and backend
- Understands scalability concepts
- Gives practical examples
