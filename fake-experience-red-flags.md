# Fake Experience Red Flags in Technical Hiring

## Resume Red Flags
- Too many technologies listed without depth
- Frequent job switches with no clear growth
- Generic project descriptions
- Copy-paste resume formatting
- Buzzword-heavy summaries

## Interview Red Flags
- Cannot explain own project architecture
- Gives textbook answers only
- Avoids deep technical discussion
- Struggles with basic debugging questions
- Cannot explain team contribution clearly

## LinkedIn Red Flags
- Sudden experience jumps
- Very few genuine connections
- No project/activity history
- Inconsistent timelines between resume and LinkedIn

## Verification Techniques
- Ask scenario-based questions
- Request architecture explanation
- Cross-check project depth
- Ask for debugging examples
- Validate ownership in previous work

## Strong Candidate Signals
- Explains tradeoffs clearly
- Gives practical examples
- Admits limitations honestly
- Understands production challenges
- Talks about impact, not only tools
